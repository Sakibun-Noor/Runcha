# Runcha — Landing Page

Single-page site for Runcha (bubble tea & desserts, Uttara, Dhaka).

## Structure
- `index.html` — the full landing page (hero, signature drinks, combo carousel, drink customizer, menu, brand story, reviews, FAQ, store locator, footer)
- `assets/` — logo, favicon, hero video, product/combo images
- `image-slot.js` — drag-and-drop image placeholder component used in a couple of sections

## Usage
Static site — no build step. Open `index.html` directly or serve the folder with any static host (GitHub Pages, Netlify, Vercel).

## Notes
- Hotline and dine-in hours are placeholders pending confirmation from management.
- Brand colors: black `#050505`, white `#FFFFFF`, red `#DC0C1C`, gold accent `#DBA632`.
